# 헐버트잡화점 — 개점 준비 실무 (자본·인프라·체크리스트)

> 🏷️ **📝 초안** · 갱신 2026-07 · 개점 준비 실무

> [`사업계획서`](사업계획서.md)는 **월 고정비와 손익분기**를 다루지만, **개점까지 드는 일시금**과 **판매·정산 인프라**는 비어 있었습니다. 이 문서가 그 빈 곳을 채웁니다.
> 문서가 아니라 '실제 문을 여는 데' 필요한 것 — ① 초기 자본 ② 판매·정산 인프라 ③ 개점 체크리스트.

**버전 v0.1** &nbsp;|&nbsp; ⚠️ 모든 금액·수량은 **예시(제안)** — 견적·실측으로 확정. 인허가·계약은 전문가(세무사·변호사) 확인 권장.

## 2. 판매·정산 인프라 — 위탁 판매의 심장

일반 소매점과 결정적으로 다른 점: **파는 물건이 내 것이 아니라 작가의 것**입니다. 그래서 "무엇이, 누구 것이, 얼마에 팔렸는가"를 **작가별로 정확히 추적**해야 정산·투명 공개([`작가-운영정책`](작가-운영정책.md) 6·7장)가 성립합니다.

### 2-1. 데이터 뼈대 — 관리코드가 전부

- 모든 작품에 **관리코드(작가코드-작품번호)**를 붙입니다(운영정책 §3에 이미 규정). 이게 판매·재고·정산을 잇는 **단일 키**입니다.
- 판매 시점에 관리코드가 기록되면 → 작가별 판매액이 자동 집계 → 월 정산 명세(운영정책 부록 C)가 거의 자동으로 만들어집니다.

### 2-2. POS(판매) 요구사항

| 요구 | 이유 |
| --- | --- |
| **관리코드/작가별 판매 기록** | 정산의 근거. 이게 안 되면 위탁 정산 불가 |
| **카드 결제 + 현금영수증** | 카드 수수료는 **회사 부담**(운영정책 §5) — 정산은 작가 책정가 기준 |
| **판매 시 재고 차감** | 재고 현황·퇴점 판단(8주 부진)의 근거 |
| **일/작가/기간별 집계 리포트** | 정산·KPI([`성과지표-KPI`](성과지표-KPI.md)) 데이터 원천 |
| **부가세 처리** | 작가 책정가 = 최종 소비자가(포함 처리, 운영정책 §5) |

### 2-3. 재고(위탁품) 관리 흐름

```
입고(작가 반입) → 관리코드 부여·등록 → 진열(칸 배정) → 판매(POS 차감)
                                        ↘ 미판매 → 로테이션 / 8주 부진 시 퇴점·반출
```

- 입고·반출 시 **작가 서명(또는 확인)** 기록 → 분실·파손 책임(운영정책 §10) 분쟁 예방.
- 재고 상태(진열중/창고/반출)를 관리코드에 태깅.

### 2-4. 도구 선택 — 1인·최소예산·단계적 *(결정 필요)*

| 단계 | 제안 | 근거 |
| --- | --- | --- |
| 0단계(팝업) | **공유 스프레드시트 + 간이 결제**(카드 단말/앱) | 초기엔 도구값보다 검증이 우선. 관리코드·판매를 시트로 수기 집계 |
| 1~2단계 | **위탁/편집숍 지원 POS** 또는 일반 POS + 정산 자동화 | 작가 수가 늘면 수기 집계가 한계 → 작가별 집계·정산이 되는 도구로 |

> `결정 필요` — POS 도구 후보 2~3개를 **① 작가/관리코드별 정산 ② 카드 수수료 처리 ③ 재고 차감 ④ 월 비용** 기준으로 비교(30분). 확정 전까지는 스프레드시트로 시작해도 무방.

### 2-5. 정산 파이프라인 (월 1회)

```
POS 판매 데이터(관리코드별) → 작가별 GMV 집계 → 수수료율 적용(일반30%/복지 누진)
   → 작가 지급액 계산 → 정산 명세(부록 C) 발행 → 계좌 입금 → 작가에게 공유(투명 공개)
```

- **안 팔린 작가는 청구·정산 없음**(운영정책 §7).
- 명세에 **판매 기록 근거**를 함께 — '투명'은 근거와 함께일 때 성립.

## 3. 개점 체크리스트

### A. 법적·행정 *(전문가 확인)*
- [ ] **사업자 등록** (업태·종목: 위탁 소매/공예품 등)
- [ ] **통신판매업 신고** — 온라인 판매·예약을 병행할 경우
- [ ] 위탁 판매의 세무 처리(부가세·소득 구분) 세무사 확인
- [ ] [`입점-동의서`](입점-동의서.md)(위탁 계약서) 변호사 검토 완료 → 작가 서명본 준비
- [ ] 개인정보처리방침·영수증·현금영수증 의무 확인

### B. 결제·정산
- [ ] 카드 가맹 계약(+PG, 온라인 시) · 결제 단말 설치
- [ ] POS/정산 도구 결정·세팅(§2-4) · 관리코드 체계 확정
- [ ] 작가별 정산 계좌 수집 양식 · 정산 명세 템플릿(부록 C) 준비

### C. 공간·안전 (한옥)
- [ ] 인테리어·수선 완료 · 매대(칸) 설치 · 조명
- [ ] **소방·안전 점검** · 소화기·화재 감지 · 대피 동선
- [ ] 작품 보험 가입 여부 결정(운영정책 §10) · CCTV
- [ ] 간판·외관(경관 규제 확인 후)

### D. 작가 온보딩 (오픈 공급)
- [ ] 첫 입점 작가 확보(모집 → 큐레이션 → 계약) — [`로드맵`](로드맵.md) Phase 3
- [ ] 관리코드 부여 · 작품 등록(부록 B) · 진열
- [ ] 온보딩 체크리스트(운영정책 부록 A) 배포

### E. 오픈 직전 최종
- [ ] 시범 판매(테스트 결제·정산 1회전) 리허설
- [ ] KPI 기록 시트 가동(개점일부터 — 채널별 유입은 소급 불가)
- [ ] [`작가-모집-키트`](작가-모집-키트.md) §6 게시 체크리스트 통과

## 4. 남은 결정 (운영자)

1. **개점 단계** — 0단계(팝업)부터 검증하며 갈지, 처음부터 2단계(전체 개관)로 갈지. (자본·리스크의 핵심 분기 — [`시장-벤치마크-개관-전략`](시장-벤치마크-개관-전략.md))
2. **한옥 임대 조건** — 보증금·권리금·수선 부담 → 1-1 표의 빈칸을 채우는 실제 견적.
3. **POS/정산 도구** — §2-4 비교 후 선택(또는 스프레드시트로 시작).
4. **작품 보험** — 가입 여부(운영정책 §10 · 로드맵 Phase 4와 연동).
